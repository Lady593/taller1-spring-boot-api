Práctica N° 1.1: Desarrollo de una API REST con Spring Boot

Repositorio correspondiente al taller individual de **Programación Avanzada** de la Universidad de las Fuerzas Armadas ESPE.

Autor: Lady Caiza

DESCRIPCIÓN DEL PROYECTO

Desarrollo de una API REST básica en Spring Boot y Spring Web para la gestión de productos de una tienda. La aplicación implementa los principios de Inversión de Control (IoC), inyección de dependencias por constructor, separación de responsabilidades (Controller, Service, Model) y un mecanismo centralizado de manejo de excepciones personalizadas.

Tecnologías Utilizadas
Java
Spring Boot(Spring Web)
Maven (Gestor de dependencias)
Navegador Web (Pruebas de endpoints)
